# 野外观测记录匿名化 API

自然保护站在公开发布野外观测记录前使用的匿名化服务。基于 **k-匿名 + 全域泛化**：
对每条记录的指定字段按层级映射做泛化（如 `云南-昆明-2024` → `云南-昆明-*` → `云南-*-*` → `*-*-*`），
并对**全部记录统一**选择每个字段的层级，使发布结果中每种字段值组合至少出现 **k** 次。

- 纯内存计算，**原始记录不落盘、不入日志**；容器以只读根文件系统、非 root 用户运行
- 自动在可行方案中最小化层级序号之和；同分时按字段名升序的层级序号字典序裁决
- Python 3.12 + FastAPI，自带 `/health` 健康检查和 Swagger 文档

## 一条命令启动

```bash
docker compose up --build -d
```

启动后：

| 用途 | 地址 |
| --- | --- |
| API 基础地址 | <http://localhost:8000> |
| 健康检查 | <http://localhost:8000/health> |
| Swagger 交互文档 | <http://localhost:8000/docs> |
| OpenAPI 描述 | <http://localhost:8000/openapi.json> |

停止：`docker compose down`；查看日志：`docker compose logs -f`。

## 配置

只有一个可选配置：宿主机暴露端口。容器内部固定监听 `8000`。

```bash
cp .env.example .env   # 修改其中的 PORT，例如 PORT=9000
```

不创建 `.env` 时默认通过宿主机 **8000** 端口访问，即 `http://localhost:8000`。

## 接口

### POST `/anonymize`

请求字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `k` | 正整数 | 每种泛化后字段值组合至少出现的次数 |
| `records` | 数组 | 原始观测记录，每条为 JSON 对象；匿名字段必须存在且为非空字符串，其他字段原样透传 |
| `fields` | 对象 | 待匿名字段，**最多 3 个**；键为字段名，值为 1~3 级映射组成的数组 |

层级约定：每字段连同恒等的层级 0 **至多 4 级**——

- 层级 `0`：原值（恒等，无需提供映射）
- 层级 `1`：数组中第 1 个映射（原值 → 泛化值）
- 层级 `2`：数组中第 2 个映射（可选）
- 层级 `3`：数组中第 3 个映射（可选），必须把该字段在全部记录中出现的所有原值收敛为**同一个统一通配符**

示例请求：

```bash
curl -s http://localhost:8000/anonymize \
  -H 'Content-Type: application/json' \
  -d '{
    "k": 2,
    "records": [
      {"id": "r1", "region": "云南-昆明-2024", "observer": "张三", "species": "黑颈鹤"},
      {"id": "r2", "region": "云南-昆明-2023", "observer": "李四", "species": "黑颈鹤"},
      {"id": "r3", "region": "云南-大理-2024", "observer": "王五", "species": "灰鹤"},
      {"id": "r4", "region": "四川-成都-2024", "observer": "赵六", "species": "灰鹤"},
      {"id": "r5", "region": "四川-成都-2022", "observer": "孙七", "species": "黑颈鹤"},
      {"id": "r6", "region": "四川-绵阳-2023", "observer": "周八", "species": "灰鹤"}
    ],
    "fields": {
      "region": [
        {"云南-昆明-2024": "云南-昆明-*", "云南-昆明-2023": "云南-昆明-*",
         "云南-大理-2024": "云南-大理-*",
         "四川-成都-2024": "四川-成都-*", "四川-成都-2022": "四川-成都-*",
         "四川-绵阳-2023": "四川-绵阳-*"},
        {"云南-昆明-2024": "云南-*-*", "云南-昆明-2023": "云南-*-*",
         "云南-大理-2024": "云南-*-*",
         "四川-成都-2024": "四川-*-*", "四川-成都-2022": "四川-*-*",
         "四川-绵阳-2023": "四川-*-*"},
        {"云南-昆明-2024": "*-*-*", "云南-昆明-2023": "*-*-*",
         "云南-大理-2024": "*-*-*",
         "四川-成都-2024": "*-*-*", "四川-成都-2022": "*-*-*",
         "四川-绵阳-2023": "*-*-*"}
      ],
      "observer": [
        {"张三": "*", "李四": "*", "王五": "*", "赵六": "*", "孙七": "*", "周八": "*"}
      ]
    }
  }'
```

为什么是这个结果：`observer` 原值两两不同，必须取层级 1；`region` 层级 0、1 时
`大理`、`绵阳` 组合各只有 1 条，层级 2 按省合并后为 3 条 / 3 条，首次满足 k=2，
层级序号之和（1+2=3）最小。

```json
{
  "k": 2,
  "total_records": 6,
  "selected_levels": {"observer": 1, "region": 2},
  "groups": [
    {"combination": {"observer": "*", "region": "云南-*-*"}, "count": 3},
    {"combination": {"observer": "*", "region": "四川-*-*"}, "count": 3}
  ],
  "generalized_records": [
    {"id": "r1", "region": "云南-*-*", "observer": "*", "species": "黑颈鹤"},
    {"id": "r2", "region": "云南-*-*", "observer": "*", "species": "黑颈鹤"},
    {"id": "r3", "region": "云南-*-*", "observer": "*", "species": "灰鹤"},
    {"id": "r4", "region": "四川-*-*", "observer": "*", "species": "灰鹤"},
    {"id": "r5", "region": "四川-*-*", "observer": "*", "species": "黑颈鹤"},
    {"id": "r6", "region": "四川-*-*", "observer": "*", "species": "灰鹤"}
  ]
}
```

### 422 错误（请求不合法时返回）

- `k` 不是正整数（`true`、字符串、0、负数均拒绝）
- 记录总数小于 `k`
- 某字段某级映射对记录中出现的某个原值**缺映射**
- 匿名字段值缺失、为 `null` 或不是非空字符串
- 待匿名字段超过 3 个，或某字段映射级数不在 1~3 之间
- 最高一级映射没有把所有原值收敛为统一通配符

错误体形如 `{"detail": "记录总数 1 小于 k=2……"}`（Pydantic 结构错误为错误数组）。

## 本地开发（不使用 Docker）

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

核心算法只依赖标准库，可直接运行单元测试：

```bash
python -m unittest discover -s tests -v
```
